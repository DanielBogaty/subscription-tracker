# Требования к приложению Subscription Tracker

## Пользовательские сценарии
1. Пользователь может добавить подписку (название, цена, период, дата)
2. Пользователь может просмотреть список всех подписок
3. Пользователь может отредактировать подписку
4. Пользователь может удалить подписку
5. Приложение автоматически проверяет изменение цен в фоновом режиме
6. Приложение уведомляет пользователя об изменении цены
7. Приложение напоминает о предстоящей оплате
8. Пользователь может просмотреть историю изменений цены
