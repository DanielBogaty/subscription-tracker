# Требования к приложению Subscription Tracker

## Пользовательские сценарии

### Управление подписками
1. Пользователь может добавить подписку (название, цена, период, дата следующей оплаты) и выбрать её тип: **Личная** (`👤`) или **Семейная** (`👨‍👩‍👧`).
2. Пользователь может просматривать единый список всех своих подписок (как личных из локальной БД, так и семейных из облака) с визуальной маркировкой типа.
3. Пользователь может отредактировать существующую подписку.
4. Пользователь может удалить подписку.
5. Пользователь может просмотреть детальную информацию о подписке и историю изменений её цены.

### Фоновый мониторинг и уведомления
6. Приложение автоматически проверяет изменение цен в фоновом режиме через `WorkManager` (для личных и семейных подписок).
7. Приложение отправляет Push-уведомление пользователю при обнаружении изменения цены и сохраняет старую цену в историю.
8. Приложение напоминает о предстоящей дате оплаты подписки.

### Авторизация и аккаунт (Firebase Auth)
9. Пользователь может зарегистрировать новый аккаунт с помощью Email и пароля (с валидацией полей и длины пароля).
10. Пользователь может войти в существующий аккаунт; сессия сохраняется между перезапусками приложения.
11. Пользователь может выйти из аккаунта по кнопке «Выйти» на главном экране.

### Функция «Семья» (Cloud Firestore)
12. Пользователь может создать новую семью и получить сгенерированный 6-значный код приглашения (`inviteCode`).
13. Другой пользователь может ввести 6-значный код приглашения и присоединиться к существующей семье.
14. Участники семьи видят актуальный список членов семьи и все семейные подписки в реальном времени.
15. Пользователь может покинуть семью в любой момент.

### Статистика и аналитика расходов
16. Пользователь может просмотреть общую сумму ежемесячных расходов по всем подпискам (с учётом пересчёта недельных, квартальных и годовых циклов к месячной стоимости).
17. Пользователь видит Топ-3 самых дорогих подписок и процентную разбивку расходов с прогресс-барами.
18. Для семейных подписок приложение автоматически рассчитывает долю оплаты каждого участника (стоимость делится поровну между всеми членами семьи).
